# 音声生成ガイド — 方式・話者・指示文(instruct)の書き方

作成日時: 2026-07-28 17:05
更新日時: 2026-07-28 17:05

Qwen3-TTS での音声生成に関する実用まとめ。モデル配布元(Hugging Face の公式 README)の情報と、本アプリでの検証結果に基づく。

## 1. 生成方式と「何を制御できるか」

| 方式 | モデル | 声質 | 話し方・感情 |
|---|---|---|---|
| ボイスクローン | 1.7B/0.6B-Base | 参照音声で自由に指定 | 参照音声から暗黙に転写(指示文は使えない) |
| プリセット話者 | 1.7B-CustomVoice | 固定9名から選択 | 指示文(instruct)で制御可能 |
| ボイスデザイン | 1.7B-VoiceDesign | 指示文で自由に設計 | 指示文で制御可能 |

- 「自分で用意した声 + 演技指示」は現状どのモデルでもできない。クローンで演技が欲しい場合は、参照音声自体をそのトーンで録るのが実用的な回避策。
- 対応言語は10言語: Chinese / English / Japanese / Korean / German / French / Russian / Portuguese / Spanish / Italian(+ Auto)。

## 2. プリセット話者(CustomVoice の9名)

公式の説明の和訳。**母語で使うと最高品質**だが、どの話者もモデル対応の全言語を話せる。

| 話者 | 声の特徴 | 母語 |
|---|---|---|
| Vivian | 明るく、少しエッジの効いた若い女性の声 | 中国語 |
| Serena | 温かく穏やかな若い女性の声 | 中国語 |
| Uncle_Fu | 低く円熟した、味のある男性の声 | 中国語 |
| Dylan | 若々しい北京の男性。クリアで自然な声質 | 中国語(北京方言) |
| Eric | 元気な成都の男性。やや掠れた明るさ | 中国語(四川方言) |
| Ryan | リズム感の強いダイナミックな男性の声 | 英語 |
| Aiden | 明るいアメリカの男性。クリアな中音域 | 英語 |
| Ono_Anna | 遊び心のある日本の女性。軽快で機敏な声質 | 日本語 |
| Sohee | 感情豊かで温かい韓国の女性の声 | 韓国語 |

日本語のセリフなら Ono_Anna が第一候補。男性声で日本語を話させる場合は Uncle_Fu(低め)や Aiden(明るめ)などを試して選ぶ。

## 3. 指示文(instruct)の書き方

自然文で書く。日本語の指示でも通る(公式例は中国語・英語)。「感情・口調」「話速・声量」「キャラ・シチュエーション」を組み合わせるのが基本形。

### 公式の例

- `用特别愤怒的语气说`(すごく怒った口調で言う)— CustomVoice
- `Very happy.` — CustomVoice
- `体现撒娇稚嫩的萝莉女声，音调偏高且起伏明显…`(甘えた幼い女声。音程は高めで抑揚が大きく、甘ったるく媚びた聴感)— VoiceDesign
- `Speak in an incredulous tone, but with a hint of panic beginning to creep into your voice.`(信じられないという口調で、しかし声に少しずつパニックが混じり始める)— VoiceDesign

### 感情・口調の例(プリセット話者/ボイスデザイン共通)

- 明るく元気に、楽しそうに話す
- すごく怒った口調で、語気を強めて
- 悲しみをこらえながら、震える声で
- 囁くように小さな声で、内緒話のように
- 落ち着いたトーンで、諭すように優しく
- 興奮して早口でまくし立てるように
- 感情を抑えた淡々とした事務的な口調で
- 泣きそうな声で、ときどき言葉に詰まりながら
- 得意げに、少し芝居がかった調子で
- 疲れ切った様子で、ため息まじりに

### 話速・声量・トーンの例

- ゆっくり落ち着いて、一語一語はっきりと
- 早口で慌ただしく
- 声を張って、遠くまで届くように
- 低く抑えたトーンで静かに

### 声の設計の例(ボイスデザイン向け: 声質そのものを記述する)

- 低くて渋い中年男性の声。落ち着いた語り口でゆっくり話す
- 高めで元気な少女の声。アニメ風の明るいテンションで
- しゃがれた老人の声。昔話を語るようにゆったりと
- ニュースキャスターのような明瞭で中立的な女性の声
- 威厳のある低音の男性ナレーション。ドキュメンタリー風
- 眠そうな気だるい若い女性の声。語尾を伸ばしがち
- ラジオDJ風の軽快でよく通る男性の声

ボイスデザインでは「声質(高さ・年齢・性別・質感)+ 話し方(速度・抑揚・感情)+ 用途イメージ(ナレーション・キャラ等)」を1〜2文にまとめると狙いどおりになりやすい。

### コツ

- 1つの指示文に詰め込みすぎない(矛盾する指示は効きが悪い)。
- テキストの内容と指示の感情が一致していると自然になる(悲しいセリフ + 悲しい指示)。モデルはテキストの意味も汲んで韻律を調整する。
- 同じ指示でも生成ごとに揺らぎがある(サンプリング生成のため)。気に入るまで数回生成して選ぶ運用が現実的。

## 4. ボイスクローンのコツ

- 参照音声は **5〜20秒程度のクリアな録音**を推奨(BGM・ノイズ・残響は品質を下げる)。公式には3秒からクローン可能。
- **文字起こし(参照テキスト)は必須**。persona 管理の「文字起こし (Whisper)」で自動生成できる。
- 話速・感情・間の取り方は参照音声から転写される。演技させたいトーンがあるなら、そのトーンで録った参照音声で persona を分ける(例: `Hanako`/`Hanako-angry`)。
- 言語は persona の設定言語が使われる(フォームで Auto の場合)。

## 5. 出力仕様・内部パラメータ

- 出力: 24kHz モノラル。アプリは WAV(PCM_16)で保存。
- サンプリング設定(モデル既定): temperature 0.9 / top_k 50 / top_p 1.0 / repetition_penalty 1.05。アプリからは変更していない。
- seed 指定は未実装(qwen-tts に seed 引数はなく、完全な再現は保証できないため。詳細は 2026-07-28 の検討記録参照)。
- モデルと生成メソッドは 1:1(Base=クローン / CustomVoice=プリセット / VoiceDesign=デザイン)。方式を切り替えると対応モデルのロードが走る。
