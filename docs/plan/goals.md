# goals — プロジェクトの目的と完成形

作成日時: 2026-07-28 10:17
更新日時: 2026-07-28 10:17

## 目的

Qwen3-TTS を使って音声(セリフ・ナレーション)を生成する、完全ローカル動作のデスクトップエディタを作る。

- クラウド API に依存せず、手元の GPU だけで動く。
- 「思いついたセリフをすぐ声にする」までの操作を最短にする。
- LLM(Gemma4)の支援で、セリフ作りからテキスト整形までをアプリ内で完結させる。

## 完成形(ユーザー体験)

[sound-effect-generator](D:\GitHub\sound-effect-generator) と同じ UX を踏襲する。

1. 左サイドバーで「生成方式・声・テキスト」などを設定する。
2. 「生成キューに追加」ボタンを押すとジョブがキューに入る。
3. 右側のリストに生成済み(および待機中・生成中)のボイスがカードとして並ぶ。
4. カードから再生(波形表示付き)・ダウンロード・削除・設定のフォームへのコピーができる。

## 対応する生成方式(3方式すべてに対応)

| 方式 | モデル | 声の指定方法 |
|---|---|---|
| Voice Clone | Qwen3-TTS-12Hz-1.7B/0.6B-Base | 参照音声(ref.wav)+文字起こしで声をクローン。persona として登録・管理 |
| プリセット話者 | Qwen3-TTS-12Hz-CustomVoice | プリセット話者名 + 指示文(instruct)で感情・演技を指定 |
| VoiceDesign | Qwen3-TTS-12Hz-VoiceDesign | 「低くて渋い中年男性の声」のような指示文だけで声を設計 |

左サイドバー上部の生成方式切替で、方式ごとに入力フォームが変わる。

## LLM(Gemma4)による支援機能

`models/gemma-4-12B-it-GGUF/gemma-4-12B-it-Q4_K_M.gguf` を llama-cpp-python でロードして使う。

1. **セリフ生成支援** — キャラ設定(口調・口癖・NG表現など)とシーン指示からセリフ本文を生成し、そのまま TTS 入力に流せる。
2. **テキスト整形・読み修正** — 読み間違えやすい漢字・数字・記号の読み調整、長文の分割など、入力テキストを TTS 向けに整える。
3. **タイトル自動生成** — 生成済みカードに付ける短いタイトルを自動生成する(失敗しても音声生成は止めない)。

## 技術方針(確定事項)

- **アプリ構成**: Electron + React + Vite のフロントエンド ⇄ ローカル FastAPI(Python)を HTTP で接続(sound-effect-generator 方式)。
- **Python 環境**: プロジェクト内蔵 runtime(`runtime/python/` + `.venv/`)で自己完結させる。システムの Python や conda に依存しない。
- **保存フォーマット**: WAV(24kHz PCM_16)。
- **モデル置き場**: `HF_HOME` をプロジェクト内 `models/` に向け、モデルはすべてプロジェクト内で管理する(voice-persona 方式)。
- **GPU 逐次実行**: 生成はサーバー側の単一ワーカーで1件ずつ処理する。

## 重視する価値

- **応答性**: キュー追加は即座に反映し、待たせる処理はすべて非同期にする。
- **完全オフライン動作**: モデル取得後はネットワーク不要。
- **既存資産の流用**: sound-effect-generator(UI・キュー・プレイヤー)と voice-persona(TTS 推論・persona 管理)の実績あるコードを最大限流用し、車輪の再発明をしない。
- **AI エージェントで開発しやすい構造**: F12 スクリーンショット機能、docs/plan による進捗管理、ハマりどころの記録を維持する。
